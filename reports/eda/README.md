# Training partition EDA notes

Generated by `src/pathsnap/eda.py` from the training directory supplied for this task. Raw data remains outside the repository. The inventory and summary JSON are the machine-readable source of these figures; they can be regenerated with the command in the root README.

## Inventory and observations

- 80 trip directories were found, with all 80 `.track`, `.nodes`, `.arcs`, and `.route` files present (320 files total).
- The tracks contain 208,417 GPS observations in total. Per-trip counts range from 361 to 19,313 (median 1,529).
- The network files contain 24,168 nodes per trip on average (median 9,608; range 299 to 155,003) and 48,461 arcs per trip on average (median 19,526.5; range 649 to 307,392).
- The reference routes contain 31,336 arc IDs in total. Route lengths range from 59 to 2,266 (median 280).
- No malformed rows, invalid geographic coordinates, non-increasing timestamps, out-of-range arc node references, or out-of-range route arc IDs were found in this pass.
- There are 208,337 consecutive GPS time intervals. 7,273 differ from one second by more than 0.05 seconds (96.5% are within that tolerance). The analysis found 1,216 intervals over five seconds, across 45 trips; trip `00000004` has the most (320).
- No isolated road nodes were found. Per-trip weak component counts range from 1 to 421 (median 20); disconnectedness should be evaluated in context of each route rather than treated as an error by itself.
- A directed endpoint discontinuity diagnostic counted 13 adjacent route-arc pairs across 10 trips. This is a follow-up item to interpret against the official label semantics; the diagnostic does not assert that a route label is wrong.
- Each trip's route arc count and GPS observation count differ substantially. The implementation therefore preserves their separate sequences and makes no row-to-row correspondence assumption.

## Limitations and next checks

This pass covers only the supplied training directory. Student-development trips were not supplied in that folder, and evaluator-testing files and labels were not accessed. The EDA does not establish how route arcs align temporally to GPS observations. Before supervised modeling, verify the label semantics and the treatment of route discontinuities with the dataset documentation or organizer. Candidate generation and candidate miss rate are not yet implemented.

The plots show training-partition size distributions and the network/GPS geometry of one real training trip (`00000046`). The interactive map shows the same trip's GPS trace and road graph. Neither visualization shows a reference or predicted route.
